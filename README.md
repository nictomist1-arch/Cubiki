# Cubiki

Браузерная мультиплеерная 3D-игра: игроки управляют персонажами на общей арене, общаются в чате и взаимодействуют друг с другом в реальном времени.

## Возможности

- **Мультиплеер в реальном времени** — синхронизация позиций через Socket.io
- **Комнаты** — одинаковое название комнаты объединяет игроков; список активных комнат на экране входа
- **Персонализация** — цвет, форма (куб, сфера, ромб, цилиндр) и размер персонажа
- **Чат** — сообщения в панели и облачко над головой (~5 сек)
- **Физика** — прыжки, приземление на других игроков, столкновения, отталкивание (E)
- **Мобильная версия** — сенсорное управление и адаптивный интерфейс
- **Игра по локальной сети** — подключение с телефона по Wi‑Fi

## Технологии

| Слой | Стек |
|------|------|
| Клиент | Three.js, Vite |
| Сервер | Node.js, Express, Socket.io |
| Сборка | Vite → `dist/` |

## Требования

- [Node.js](https://nodejs.org/) 18 или новее
- npm

## Установка

```bash
git clone <url-репозитория>
cd Cubiki
npm install
```

## Запуск

### Продакшен (рекомендуется)

Соберите клиент и запустите сервер:

```bash
npm run build
npm start
```

Откройте в браузере: **http://localhost:3000**

Сервер слушает все интерфейсы (`0.0.0.0`), поэтому в консоли будут показаны адреса для подключения с других устройств в сети, например:

```
http://192.168.0.16:3000
```

### Режим разработки

```bash
npm run dev
```

Запускаются одновременно:
- сервер на порту **3000**
- Vite dev-сервер на порту **5173**

Для разработки UI удобен `http://localhost:5173`. Для игры с телефона используйте **порт 3000**.

> После изменений в коде клиента для продакшена выполните `npm run build` и перезапустите сервер.

## Как играть

### Вход в игру

1. Введите имя.
2. Укажите комнату (по умолчанию `lobby`) или выберите из списка активных.
3. Настройте внешний вид персонажа.
4. Нажмите **«Войти в игру»**.

Можно сразу открыть нужную комнату по ссылке: `http://localhost:3000?room=pvp`

### Управление (ПК)

| Клавиша | Действие |
|---------|----------|
| **W A S D** | Движение |
| **Пробел** | Прыжок |
| **E** | Отталкивание ближайших игроков |
| **T** | Фокус на поле чата |
| **Enter** | Отправить сообщение |
| **📷** | Сбросить камеру |
| **🎨** | Панель персонализации в игре |

Камеру можно вращать мышью (OrbitControls).

### Управление (мобильные)

- Стрелки на экране — движение
- **Прыжок** / **Толчок** — соответствующие действия
- Жесты — вращение камеры

## Комнаты

- Название комнаты: латиница, цифры, `_` и `-`, до 16 символов.
- Игроки в разных комнатах не видят и не взаимодействуют друг с другом.
- Список комнат обновляется на экране входа; API: `GET /api/rooms`.

## API

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/api/info` | Порт и локальные URL для подключения |
| `GET` | `/api/rooms` | Список активных комнат и число игроков |

## Сеть и устранение неполадок

**Телефон не подключается**

- Убедитесь, что телефон и ПК в одной Wi‑Fi сети.
- Используйте адрес из консоли сервера (`В сети: http://...`), не `localhost`.
- Разрешите входящие подключения на порт **3000** в брандмауэре Windows.

**«Подключение к комнате…» не исчезает**

- Остановите все старые процессы сервера и запустите заново: `npm start`.
- Обновите страницу с очисткой кэша: **Ctrl+F5**.

**Изменения не применяются**

- Выполните `npm run build` перед `npm start`.
- Не смешивайте старый сервер с новым клиентом из `dist/`.

**Порт занят**

```bash
# Windows PowerShell — найти процесс на порту 3000
Get-NetTCPConnection -LocalPort 3000 | Select-Object OwningProcess
```
